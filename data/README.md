# Учебные данные

В Git хранятся только небольшие данные, которые разрешено распространять.
Крупные или производные наборы размещаются локально в `data/raw/` и
игнорируются Git.

Для каждого набора данных зафиксируйте:

- название и ссылку на источник;
- лицензию;
- дату скачивания или версию;
- систему координат;
- команду получения и подготовки;
- контрольную сумму, если источник может измениться.

Рекомендуемая локальная структура:

- `data/raw/` — неизменённые исходные файлы;
- `data/interim/` — промежуточные результаты;
- `data/processed/` — компактные учебные выборки.
