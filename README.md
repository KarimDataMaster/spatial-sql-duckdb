# Spatial SQL с DuckDB

Практический учебный курс по пространственному SQL и алгоритмам в DuckDB.
Материалы курса публикуются как статический сайт через GitHub Pages.

## Что находится в репозитории

- `docs/` — страницы сайта, теория и инструкции к практикам;
- `notebooks/` — готовые Jupyter Notebooks для уроков и самопроверки;
- `sql/` — стартовые SQL-скрипты по модулям;
- `data/` — правила получения и хранения учебных данных;
- `requirements-course.txt` — зависимости курса для установки через `pip`;
- `mkdocs.yml` — навигация и настройки сайта;
- `.github/workflows/` — автоматическая проверка и публикация сайта.

## Быстрый старт

Требуется Python 3.11+.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements-docs.txt
mkdocs serve
```

После запуска сайт доступен по адресу <http://127.0.0.1:8000>.

Проверка production-сборки:

```powershell
mkdocs build --strict
```

## Публикация

После push в `main` workflow собирает сайт и публикует его в GitHub Pages.
Один раз включите источник публикации:

1. Откройте репозиторий на GitHub.
2. Перейдите в **Settings → Pages**.
3. В **Build and deployment → Source** выберите **GitHub Actions**.

Сайт будет доступен по адресу:
<https://karimdatamaster.github.io/spatial-sql-duckdb/>.

## Как добавлять модуль

1. Создайте страницу в `docs/modules/`.
2. Добавьте практический SQL в отдельную папку внутри `sql/`.
3. Включите страницу в `nav` файла `mkdocs.yml`.
4. Локально выполните `mkdocs build --strict`.

Для нового урока удобно использовать структуру:

- результат обучения;
- необходимые знания;
- короткая теория;
- демонстрация;
- самостоятельная практика;
- вопросы для самопроверки;
- дополнительные материалы.
