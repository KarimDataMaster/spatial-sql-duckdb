# Модуль 6. Итоговый проект

## Задача

Выполнить законченный пространственный анализ на открытых данных и сделать
его воспроизводимым для другого участника курса.

## Обязательные части

- ясный исследовательский вопрос;
- ссылка на источник и дата получения данных;
- описание системы координат;
- SQL-пайплайн подготовки и анализа;
- проверки качества результата;
- краткое объяснение ограничений;
- инструкция запуска из чистого окружения.

## Критерии оценки

| Критерий | Проверка |
|---|---|
| Воспроизводимость | Проект запускается по инструкции |
| Корректность | Единицы, CRS и предикаты обоснованы |
| Проверяемость | Есть контрольные количества и проверки |
| Ясность | Запросы и выводы можно проследить |
| Эффективность | Производительность измерена на целевых данных |
