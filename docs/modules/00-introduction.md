# Модуль 0. Введение

## Результат обучения

Перед началом модуля пройдите урок
**[Рабочее окружение на Windows](../setup/windows-jupyter.md)** и убедитесь,
что проверочный notebook выполняется без ошибок.

Вы понимаете устройство курса, запускаете DuckDB и подключаете расширение
`spatial`.

## Темы

- аналитическая база DuckDB;
- встраиваемая архитектура и файловые форматы;
- установка и загрузка расширений;
- первый объект `POINT`;
- воспроизводимая структура SQL-проекта.

## Демонстрация

```sql
INSTALL spatial;
LOAD spatial;
SELECT ST_AsText(ST_Point(0, 0));
```

## Готовность модуля

Вы можете открыть DuckDB, загрузить `spatial` и выполнить первый запрос из
`sql/00_introduction/01_first_query.sql`.
