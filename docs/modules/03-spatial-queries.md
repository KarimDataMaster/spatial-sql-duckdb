# Модуль 3. Пространственные запросы

## Результат обучения

Вы используете пространственные предикаты и соединяете таблицы по взаимному
положению объектов.

## Темы

- `ST_Intersects`, `ST_Within`, `ST_Contains`;
- расстояние и поиск ближайших объектов;
- spatial join;
- граничные случаи предикатов;
- проверка результата соединения.

## Практика

Назначить каждой точке полигон, в котором она находится, затем отдельно
обработать точки на границе и точки вне всех полигонов.

Критерий готовности: число исходных точек согласуется с числом сопоставленных
и несопоставленных записей.
