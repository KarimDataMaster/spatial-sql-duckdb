# Модуль 4. Анализ и агрегирование

## Результат обучения

Вы собираете несколько пространственных операций в прозрачный аналитический
пайплайн.

## Темы

- буферы и зоны доступности;
- пересечения и объединения;
- агрегирование по территориям;
- оконные функции вместе с spatial SQL;
- экспорт результата.

## Практика

Рассчитать показатель обеспеченности объектами для набора территорий:
подготовить геометрии, выполнить пространственное соединение, агрегировать
метрику и экспортировать итоговую таблицу.
