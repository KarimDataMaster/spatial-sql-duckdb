# Spatial SQL с DuckDB

Практический курс о том, как решать задачи геоаналитики средствами SQL:
от чтения пространственных данных до пространственных соединений,
агрегирования и оптимизации запросов.

## Для кого этот курс

Курс подойдёт аналитикам, инженерам данных и разработчикам, которые уже
знакомы с базовым SQL и хотят работать с геоданными без тяжёлой серверной
инфраструктуры.

## Чему вы научитесь

- запускать DuckDB и подключать расширение `spatial`;
- читать GeoJSON, GeoPackage, Shapefile и Parquet;
- понимать геометрии, системы координат и пространственные предикаты;
- строить spatial join и аналитические пайплайны;
- измерять производительность и улучшать запросы;
- оформлять воспроизводимый итоговый проект.

## Формат

Каждый модуль состоит из короткой теории, демонстраций, SQL-практики и
вопросов для самопроверки. Файлы для выполнения заданий находятся в папке
`sql/` репозитория.

| Этап | Результат |
|---|---|
| Подготовка | DuckDB работает локально, расширение `spatial` подключено |
| Основы | Вы читаете и преобразуете геометрии |
| Анализ | Вы выполняете пространственные фильтры и соединения |
| Оптимизация | Вы оцениваете план и стоимость запросов |
| Проект | Вы публикуете воспроизводимый пространственный анализ |
