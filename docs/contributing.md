# Участие в проекте

## Изменение материалов

1. Создайте отдельную ветку.
2. Измените Markdown и связанные SQL-файлы.
3. Проверьте локальную сборку командой `mkdocs build --strict`.
4. Откройте pull request с описанием учебной цели изменения.

## Требования к уроку

- сформулирован наблюдаемый результат обучения;
- все команды можно скопировать и выполнить;
- указан источник данных;
- ожидаемый результат не зависит от локальных абсолютных путей;
- термины используются последовательно;
- присутствуют критерии завершения практики.

## Стиль SQL

- ключевые слова — в верхнем регистре;
- один логический шаг — один CTE;
- поля перечисляются явно;
- у пространственных столбцов понятные имена;
- комментарии объясняют решение, а не повторяют синтаксис.

## Проверка ссылок и навигации

`mkdocs build --strict` завершает сборку с ошибкой при ряде проблем в
конфигурации и материалах. Выполняйте её перед каждым pull request.
